# Отдел BTC-агентов

Приложение, в котором десять агентов торгуют биткоином на демосчёте. У каждого агента своя теория рынка.
Над ними стоит руководитель отдела, рядом работает отдел исследований, а над всеми — жёсткий риск-менеджер.
Панель открывается в браузере на телефоне и на компьютере и ставится на телефон как приложение (PWA).

## Что такое демосчёт (бумажная торговля)

Котировки настоящие, с биржи, в реальном времени. Деньги виртуальные: у каждого агента 1000 USDT,
которых не существует. Все сделки считаются по реальной цене с учётом комиссии биржи и проскальзывания.
Это позволяет месяцами проверять, кто из агентов действительно зарабатывает, ничем не рискуя.
Перевод на реальные деньги — отдельный шаг, который делается только по вашему решению.

## Кто есть кто

| Роль | Что делает | Кто решает |
|---|---|---|
| 8 агентов на правилах | SMA-тренд, EMA-импульс, RSI, Боллинджер, пробой Donchian, MACD, всплеск объёма, режим волатильности (ATR) | код |
| 2 нейро-агента | «Технарь» читает свечи и уровни, «Стратег» определяет режим рынка. Работают через Claude API | нейросеть, но сделку одобряет риск-менеджер |
| Риск-менеджер | Дневной лимит убытка агента (3%) → пауза до конца дня. Просадка от пика (10%) → увольнение. Дневной убыток отдела (2%) → всё закрыть и стоять до завтра. Спот, без плеча, без шортов | код, окончательно |
| Руководитель отдела | Увольняет по сигналу риск-менеджера, нанимает замену со скамейки, раз в сутки пишет отчёт и предлагает уволить худшего | код, нейросеть только пишет отчёт |
| Отдел исследований | Перебирает семейства стратегий и параметры, гоняет бэктест на истории, лучших кладёт на «скамейку запасных» | код |
| Обучение | Каждому решению через 4 часа проставляется результат. Из ошибок нейро-агентов раз в сутки формируется «урок», который попадает в их промпт. Параметры агентов на правилах раз в неделю перепроверяются на свежей истории | код + нейросеть |
| Владелец (вы) | Одобряете или отклоняете заявки: найм (если выключен автонайм), увольнение по итогам 14 дней, позже — переход на реальные деньги | вы |

Решения принимаются раз в час, по закрытию часовой свечи.

## Быстрый старт

```bash
git clone https://github.com/Alimanabu/Trader-bot.git
cd Trader-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впишите ANTHROPIC_API_KEY, если хотите включить нейро-агентов
python -m trader serve
```

Откройте http://localhost:8080. На телефоне: откройте адрес сервера в браузере и выберите «Добавить на главный экран».

Без ключа Claude система работает целиком, просто два нейро-агента держат позицию и ждут ключ.

### Через Docker

```bash
cp .env.example .env
docker compose up -d
```

База данных и журнал лежат в папке `data/`.

## Команды

```bash
python -m trader serve            # панель + планировщик (основной режим)
python -m trader tick             # выполнить один шаг вручную
python -m trader research         # запустить отдел исследований, показать кандидатов
python -m trader simulate --hours 500   # прогнать отдел по синтетической истории (проверка логики без интернета)
python -m pytest                  # тесты
```

## Настройки

Все параметры в `.env.example` с пояснениями. Главные:

- `MARKET_SOURCE` — `binance` (по умолчанию, с автоматическим запасным Bybit) или `bybit`.
- `AGENT_DAILY_LOSS_LIMIT`, `AGENT_MAX_DRAWDOWN`, `DEPT_DAILY_LOSS_LIMIT` — лимиты риска.
- `AUTO_HIRE` — нанимать замену автоматически (`true`) или спрашивать вас (`false`).
- `LLM_MODEL` — модель Claude для нейро-агентов и отчётов.

## Как устроен код

```
trader/
  engine.py      один тик: свечи → агенты → риск → счёт → журнал → обучение → руководитель
  risk.py        жёсткие лимиты, без нейросети
  manager.py     руководитель: увольнение, найм со скамейки, отчёт
  research.py    бэктест и подбор кандидатов
  learning.py    результаты решений, уроки, переподбор параметров
  journal.py     SQLite: решения, сделки, капитал, события, заявки
  paper.py       демосчёт: спот, без плеча, комиссии, проскальзывание
  llm.py         единственная точка обращения к Claude API (строгий JSON по схеме)
  agents/        8 стратегий на правилах + 2 нейро-стратегии
  data/          котировки Binance/Bybit, синтетический рынок, индикаторы
  api.py, scheduler.py, cli.py
web/             панель (PWA)
tests/           42 теста
```

## Что дальше

1. Запустить на сервере, который работает круглосуточно, и дать системе поработать 4–8 недель на демосчёте.
2. Подключить уведомления (Telegram) о заявках на ваше решение.
3. По итогам демо-периода перевести на реальные деньги только агентов с устойчивым плюсом, и с маленького капитала.
